Architecture

7-layer governance stack.

Every request passes through seven deterministic layers before a model produces output. No layer is optional. Every layer has a defined failure mode.

L1
Transport Boundary Guard

Evaluates packet origin metadata against trusted proxy mappings.

Hard drop
L2
PII Inspection Filter

Runs local WebAssembly filters to mask protected identifiers before contextual analysis.

Strip + redact
L3
Intent Boundary Validator

Structural token checking to block alignment attacks and out-of-scope prompts.

Policy violation
L4
Deterministic Router

Matches workloads to available local compute. No routing to multi-tenant clouds.

Local-only exec
L5
Context Provenance Matcher

Attaches verified origin metadata from MirrorDNA to link requests to a unique provenance path.

Drop context
L6
Cryptographic Sign-off

SHA-256 state hashes and Ed25519 signatures via MirrorSeed tokens. Tamper-evident by construction.

Invalidate trace
L7
Append-Only Ledger Commit

Binds the transaction block into a local tamper-evident audit history structure.

No rollback
Sovereign Deployment

Your data never leaves your boundary.

Three deployment models. All sovereign. Choose based on your threat model, not our convenience.

Air-Gapped

Complete network isolation. Models, data, and inference run entirely within your physical boundary. No external calls, no telemetry, no cloud dependency.

  • Zero network egress
  • On-premise hardware
  • Full data sovereignty
  • HSM key management

Single-Tenant VPC

Dedicated cloud infrastructure with no shared resources. Your models run in isolated compute with private networking and customer-managed encryption keys.

  • Dedicated compute
  • Private networking
  • CMEK encryption
  • SOC 2 boundary

Local Edge Inference

Run quantised models on commodity hardware at the edge. Branch offices, factory floors, field deployments. No cloud round-trip required.

  • Quantised models
  • ARM / x86 support
  • Offline-capable
  • < 10ms latency
